# Contributing

This repository is primarily for personal Codeforces practice, but contributions are welcome if they improve clarity, structure, or documentation.

## Guidelines

- Keep solutions readable and easy to follow.
- Use clear file names that match the problem or topic.
- Add comments only when they help explain a non-obvious approach.
- Keep changes focused and relevant to the repository.

## How to Contribute

1. Open a pull request with a clear description of your change.
2. Mention what problem or improvement the change relates to.
3. Make sure your updates are consistent with the style of the existing repository.
